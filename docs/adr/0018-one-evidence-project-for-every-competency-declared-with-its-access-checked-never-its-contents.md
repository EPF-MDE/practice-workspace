# One Evidence Project for every Competency, declared with its access checked, never its contents

A Student may put their evidence in another repository than the one the Roster names, until the Reading Day. As they declare it, they need to know whether the Reading Day will be able to read it, and what the Evidence panel shows must be what the Reading Day would find. Reading its contents at that point would read a repository the Student has not yet agreed to show, and GitLab gives the Practice workspace no way to check. **So a Student declares one Evidence Project for every Competency, with a note on what to read, and a declaration checks access only, never contents: a GitHub repository is readable when it is public or when the Student Connector (ADR-0004) is installed on it, and a GitLab project gets no check, only the instruction to give the Instructor Reporter access. Each Evidence panel checks that access again on every reading.**

- `declare_evidence_project` in `backend/app/practice/_internal/evidence_panel.py` declares or changes it; `withdraw_evidence_project` withdraws it, and the Reading Day reads the Roster's Evidence Project again. Both are refused after the Reading Day. The Evidence panel tells the Student who reads what they declare (`DeclarationHelp` in `backend/app/evidence_panel/panel.py`).
- A declaration is stored with its access as checked when declared (`_declaration_payload` in `backend/app/practice/_internal/evidence.py`), but every reading checks it again (`_declared`): the Student Connector may have been installed since.
- Checking a repository's access before declaring it (`check_project_access`), and refreshing an Evidence panel (`refresh_evidence_panel`), store nothing in the Student's record.
- `access` in `backend/app/evidence_panel/access.py` returns an `Access`. The Roster's own Evidence Project is always readable. Otherwise `AppAccessCheck` asks `GET /repos/{repo}/installation` with the App's JWT, which answers 200 when the App is installed with access to that repository, then falls back to whether the repository is public; it never requests `/contents`.
- `AppAccessCheck.can_read` answers readable, not readable, or `None` when it could not check: GitHub answering an error other than 404, or the App without credentials. The Student reads `None` as not readable yet, never as readable. Each answer is kept a minute (`TTL`).
- An Evidence panel exists for every Competency the Repository reading knows (`COMPETENCIES`), even before the Course folder gives that Competency content (`_competency`).
- The declared Evidence Project's URL is the default repository of a Transfer step in the Evidence Plan's draft, when the Student's answer to that step names none (`_transfer` in `backend/app/practice/_internal/review.py`).
